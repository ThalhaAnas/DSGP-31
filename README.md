# Intelligent Traffic Light System

## Overview
A simulation-based intelligent traffic light system developed using machine learning and SUMO traffic simulation to optimize urban traffic flow in Sri Lanka. The system dynamically adjusts traffic signal timings based on real-time traffic conditions.

## Features
- Adaptive traffic signal control
- Traffic congestion prediction
- Waiting time prediction
- Throughput analysis
- Real-time traffic simulation
- Machine learning integration
- Performance evaluation dashboard

## Project Objectives
- Reduce traffic congestion
- Improve vehicle throughput
- Minimize waiting time
- Optimize signal timing dynamically
- Simulate intelligent traffic control strategies

## Technologies Used
- Python
- SUMO (Simulation of Urban Mobility)
- OpenStreetMap (OSM)
- Machine Learning
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## System Components

### Traffic Simulation
Uses SUMO to simulate:
- Vehicle movement
- Traffic signals
- Road networks
- Traffic density

### Machine Learning Models
Used for predicting:
- Congestion levels
- Waiting times
- Travel duration
- Traffic throughput

### Adaptive Signal Control
Dynamically changes signal durations using:
- Vehicle count
- Queue length
- Real-time traffic flow
